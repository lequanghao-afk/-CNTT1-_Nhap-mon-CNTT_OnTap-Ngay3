
# Trung tâm Tiếng Anh (TTA)

## Giới thiệu

Dự án **quản lý khóa học** và *đăng ký học viên* tại TTA.

## Cấu trúc thư mục

| Thư mục | Nội dung |
|---|---|
| data/ | Dữ liệu Excel |
| docs/ | Tài liệu dự án |
| logs/ | Nhật ký hệ thống |
| media/ | Tệp hình ảnh, âm thanh |

## Quy trình đăng ký học

1. Chọn khóa học phù hợp.
2. Điền thông tin đăng ký.
3. Nhận xác nhận từ trung tâm.

## Kiểm tra dự án

```powershell
Get-ChildItem
```
